# Money Manager store graphics

The 16 original screenshots were removed from the repository at the user's
request and moved to desktop Trash, where they can be restored.
Seven marketing graphics were generated with the built-in image-generation tool
and saved in `exports/`. Exact prompts are in `PROMPTS.md`.

## Review before publishing

These are AI-composited graphics, not pixel-identical screenshots. The floating
development gear was removed. Small UI details can differ from the source;
for example the generated chart legend shows Transport as 367.65 while the
light source shows 366.65. Review these as marketing drafts before publishing.
The original Expenses captures also contain seeded notes such as "Test expense".

All seven outputs are opaque RGB PNGs at **941 × 1672**. The generator returned
this size despite the requested 1080 × 1920. They meet Play's basic screenshot
dimension range, but are below its 1080 × 1920 portrait recommendation criteria.
Do not describe these as native 1080p exports.

Official guidance: https://support.google.com/googleplay/android-developer/answer/9866151
